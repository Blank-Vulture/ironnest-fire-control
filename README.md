# Iron Nest Fire Control

Iron Nest 用の射撃補助ツール。地図で測った **方位角と射程** から、
**仰角・装薬・飛翔時間・発射時刻** をまとめて出し、
**砲塔の旋回が最小になる順** に左右の砲へ振り分けます。

ゲーム内では目標 1 体ごとに「地図に赤線を引く → クリップボードに方位角と射程が記録される →
弾道計算機でカードを刷る」を繰り返します。このツールはその 2 番目から先を引き受けます。

## 使い方

1. ゲーム内クリップボードの下線部を見て、**数字だけ**を打つ。
   方位角 → `Enter` → 射程 → `Enter` で 1 件登録。テンキーから手を離す必要はありません。
   単位（`°` `km`）も区切りの `/` も打たなくて構いません。
2. カードが射撃順に並びます。1 行が「左を撃つ → わずかに旋回 → 右を撃つ」の 1 組です。
3. 着弾時刻の指定がある目標だけ、着弾時刻を入れると発射時刻が出ます。
4. 撃ったら **撃った** を押す。薬莢が排出されて次弾が送り込まれ、射撃順が組み直されます。

OCR などで `273.9° / 6.16km` の書式ごと持ってきた場合は、そのまま**貼り付け**れば読みます。
複数行まとめて貼れば一度に登録されます。

カード上で変えられるもの:

| 項目 | 既定 | 備考 |
| --- | --- | --- |
| 弾種 | HE | 20 種。射程・仰角・飛翔時間には影響しません |
| 装薬 | 自動 | 届く最小の装薬。上げると仰角が下がり飛翔時間も短くなります |
| 砲 | 自動 | 射撃順から交互に割り当て。`L` / `R` を押すと固定 |
| 着弾時刻 | — | 数字だけ打てばコロンが入ります（`101010` → `10:10:10`） |

## 計算

すべてゲーム内の弾道計算機と同じ式です（近似ではありません）。

**仰角** — 装薬 N の最大射程は `5N km`。0 km を 0°、最大射程を 60° として線形に写す:

```
仰角 = 距離 × 12 ÷ 装薬数
```

ゲーム内で提示される手計算の式と一致します。最低仰角の制限はありません。

**飛翔時間** — 弾速は弾種によらず基本 0.7 km/秒。装薬が smoothstep で倍率を掛けます:

```
u    = (装薬数 − 1) ÷ 5
弾速 = 0.7 × [0.3 + 0.7 × (3u² − 2u³)]   km/秒
飛翔 = 距離 ÷ 弾速
```

装薬 1〜6 での弾速は `0.21000 / 0.26096 / 0.38248 / 0.52752 / 0.64904 / 0.70000` km/秒。
発射レバーを引いてから砲弾が出るまでのわずかな間は含まれません。

**発射時刻** — `着弾時刻 − 飛翔時間`。どちらもゲーム内の時間軸の値なので、
出てくる発射時刻もそのままゲーム内時計で読めます（現実の時計とのズレは無関係）。
端数は近い方の秒に丸めます。

## 装填の見取り図

砲塔の図の左右の余白に、その砲がこれから撃つ弾が上向きに並びます。弾体には弾種コードが
縦書きで入っているので、**左に何を、右に何を込めるか**が弾の並びそのもので分かります。
弾は砲塔側の端から詰まり、いちばん砲に近いものが次弾です。

- **塗りつぶしの弾** … 全体で次に火を噴く 1 発。その砲身と `L` / `R` も橙になります。
- **輪郭だけの弾** … その砲の次弾。左右とも装填できるので両側に出ます。

**撃った** を押すと薬莢が排出され、残りが砲側へ送り込まれます。

### 装填数の上限と補給

砲塔後部の回転式弾倉は **1 基 6 発**、これが 2 基あって即応弾は計 12 発です。
これを超えるぶんは補給トラックから砲塔後部へ揚弾することになります。

そこで、片側 7 発以上を抱えている砲は**弾架が 2 段**になります。

- **1 段目**（実線） … 弾倉の即応弾 6 発
- **2 段目**（破線） … まだ砲塔に積んでいないぶん

1 発撃つごとに残りが砲側へ送られ、2 段目の弾は 1 段目へ降りてきて実線に変わります。
見出しには `8 発 補給 2` のように、補給が要る発数が出ます。

射撃順の側でも、即応弾を撃ち切る 1 発の手前に **「下記の弾を補給してください」** が挟まり、
その砲に何を何発目に上げればよいかが順に並びます。図に出るのは 2 段（12 発）までで、
それを超えるぶんは `+N` と出ます。

## 射撃順

砲塔の旋回は左右の砲で共通なので、連続射撃の律速は方位の修正です。そこで:

- 目標を方位順に並べ、**いちばん広く空いている隙間の直後から一方向に回る**。
  こうすると全目標を撃ち終えるまでの旋回量が「一周 − 最大の隙間」で最小になります。
- 左右の砲を**交互に**割り当てる。片方が飛んでいる間にもう片方を装填でき、
  旋回もカード間に表示されるぶんだけで済みます。
- 砲を手で固定して同じ砲が続いた場合は、装填待ちになる旨を表示します。

1 発撃つと、砲塔はその目標の方位を向いたままになります。そこで **撃った** を押した目標の
方位と使った砲を引き継ぎ、続きから組み直します。

- 残りの目標を覆う弧に対して、**手前端に寄って時計回り**に舐めるか、**奥端に寄って反時計回り**に
  舐めるかの、寄せる距離が短い方を選びます。後者では左回りの旋回が出ます。
- 左右の割り当ても直前に使った砲の続きから振ります。これをやらないと 1 発撃つたびに
  左右が入れ替わり、先に装填しておいた弾が無駄になります。

## 開発

```
npm install
npm run dev        # 開発サーバ
npm test           # ロジックのテスト
npm run typecheck  # 型チェック
npm run build      # dist/ を生成
```

計算ロジックは UI から切り離して [`src/lib/`](src/lib/) に置いてあります。

| ファイル | 役割 |
| --- | --- |
| [`ballistics.ts`](src/lib/ballistics.ts) | 仰角・射程・弾速・飛翔時間・方位差 |
| [`time.ts`](src/lib/time.ts) | 時刻と時間の解析・整形。内部表現は「0 時からの経過秒」 |
| [`shells.ts`](src/lib/shells.ts) | 砲弾 20 種の諸元 |
| [`guns.ts`](src/lib/guns.ts) | 左右の砲の識別 |
| [`targets.ts`](src/lib/targets.ts) | 目標の取り込み・解・射撃計画 |

機能を足すときは、まずここに純粋関数とテストを足してから UI を繋いでください。
UI 側（[`src/components/`](src/components/)）は表示だけを持ち、計算は持ちません。

> 入力欄の並びと結果の並びは分けてあります。結果は方位順に並べ替わるので、
> 入力欄をその順で描くと、打っている最中に行が動いて別の目標に文字が入ります。

## デプロイ

`main` に push すると GitHub Actions が型チェック・テスト・ビルドを通して GitHub Pages に公開します。
リポジトリの Settings → Pages → Source を **GitHub Actions** にしておいてください。
公開パス（`/<リポジトリ名>/`）はワークフローがリポジトリ名から自動で決めます。
